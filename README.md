# Haferbot

Bot versions for stages 1 to 6 are uploaded. The bots for stages 2, 3, and 5 work flawlessly. The stage 1 bot works too, but its exploration algorithm isn't great and takes a relatively long time to calculate. For stage 4, I didn't want to deal with noisy sum signals, so I didn't put as much work into it and the stage 6 bot actually works very well, though it does crash occasionally in PvP.
